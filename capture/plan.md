# Portfolio presentation refresh

Lane: reference build. The user supplied Rocket Web Labs as a design and
micro-interaction reference for their own existing portfolio, not a request to
reproduce the agency's identity. Stack stays React + Vite + GSAP; content stays
in src/data.js. All project media, credits and case studies are retained.

Reference: https://www.rocketweblabs.com/ (22 October 2026).
Skill: TerminalSkills/skills, skills/clone-website, installed through the Codex
skill installer. The npm wrapper is not required to use the same skill.

Pattern brief:
- Large, left-aligned hero typography over immersive imagery.
- Inset navigation, short labels, a clear primary action.
- Generous section spacing, large project previews, compact supporting copy.
- Short colour transitions on controls; image and text state changes.
- Responsive navigation and deliberate mobile typography.

Zoh's direction: an exhibition index for art, code and responsive spaces.
Charcoal and chalk surfaces with the existing lilac/lime identity. Existing
Space Grotesk and Playfair Display provide distinct display roles. Hero scenes
use Zoh's documented Mycelial Stage and Signals projects. No reference assets,
fonts, scripts, logos, analytics, or copy are imported.

Build order: navigation and hero; project index; practice, experience and
contact; motion/accessibility; production preview at 390, 768 and 1440px.
Acceptance: visual review rather than pixel parity; working galleries, filters,
project links, résumé, menu and theme toggle; no overflow; reduced-motion
support; keyboard paths and media requests checked. Local preview only.
